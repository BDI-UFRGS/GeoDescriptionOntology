# GeoDescription Ontology

Description: An IAO-based ontology to represent informational entities needed to create geological descriptions.

More information can be found at http://obofoundry.org/ontology/geodsc

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

https://www.inf.ufrgs.br/bdi/ontologies/geodsc.owl

(note this will not show up until the request has been approved by obofoundry.org)

### Editors' version

Editors of this ontology should use the edit version, [src/ontology/geodsc-edit.owl](src/ontology/geodsc-edit.owl)
